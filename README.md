> 网页版总览：[index.html](./index.html)（双击打开，能搜索能筛选）

## 规矩

1. 一天一个文件，文件名就是日期
2. 开头放「速览表」：主题 + 一句话记住 + 分类
3. 中间写学习经历（时间线），再放详细笔记
4. 涉及命令/代码行为，**先在 `/tmp` 实测再写**
5. 新增或改动日记后，让我重新生成 `index.html`
